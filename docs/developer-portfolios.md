## 1. Overview & Purpose

`emmabostian/developer-portfolios` is one of the most popular and celebrated open-source showcases for developer portfolios on GitHub. 

Originally inspired by [Ali Spittel's tweet](https://twitter.com/ASpittel/status/1171604728951779328), this project serves as a collaborative, living directory of developer personal websites from around the world. It provides developers, engineers, and designers with real-world layout, visual identity, copywriting, and interactive UX inspiration.

## 3. How to Submit Opu's Portfolio to the List

When Opu's portfolio is deployed online (e.g. on Vercel, Netlify, or custom domain), it can be submitted to this repository to gain international exposure and backlink authority.

### Submission Guidelines:
1. **Fork the Repository:**
   ```bash
   git clone https://github.com/<your-username>/developer-portfolios.git
   cd developer-portfolios
   git remote add upstream https://github.com/emmabostian/developer-portfolios.git
   ```
2. **Create a Branch:**
   ```bash
   git checkout -b add/estakball-hossain-opu
   ```
3. **Add Your Entry Alphabetically in `README.md`:**
   In the alphabetical section corresponding to the first letter (e.g., `## E` or `## O`):
   ```markdown
   - [Estakball Hossain (Opu)](https://your-portfolio-url.com) [Marketing & Business Operations Specialist | Front-End & Analytics]
   ```
4. **Commit & Push:**
   ```bash
   git add README.md
   git commit -m "Add site Estakball Hossain (Opu)"
   git push origin add/estakball-hossain-opu
   ```
5. **Open a Pull Request:**
   Submit a PR against `emmabostian/developer-portfolios:master`. Automated tests will verify formatting and URL validity.
